# 모바일 Foundation의 소비 개발 안내 보강

소비 개발자가 새 CSS·화면을 만들기 전에 기존 프레임·매크로·토큰을 찾고 상태와 검증 범위를 정하도록 안내한다. 2026-11-27 사용자 요청에 따른 구현 설계다.

현재 wheel은 CSS·템플릿·HTML 검사기를 제공하지만 원본 저장소 밖에서 읽을 방법론 안내가 없다. 패키지 DEVELOPMENT.md에 기술별 재사용 지도와 화면 상태→작은 렌더→DOM 검사→실제 입력·화면 확인 순서를 제공한다. `python -m mobile_foundation.guide`는 설치된 원문을 읽어 출력하며 파일 수정·네트워크 접근·추가 의존성이 없다. 원본 저장소 AGENTS/README에서도 이 문서를 참조한다.

wheel 독립 검증에서 CLI를 실행하고 FastAPI 없이 안내가 배포됐는지 확인한다. 지침 전달은 판단의 자동 집행을 뜻하지 않는다. 기존 DOM 검사·포맷·타입·렌더 테스트를 유지한다.
